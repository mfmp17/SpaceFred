## Major
- Made Dwindle the default layout, with `Dwindle | Columns` in Settings › Layout: new windows split the longer side of a tile (so portrait windows tile sanely), and the tree re-orients when a sibling closes and the tile becomes tall.
- Added window gaps, screen-edge padding, and a single-window width for wide displays. Inner gaps, the four outer edges and `gaps.outer` are configured in `[settings.gaps]`, with one Window gaps slider and a redrawn Layout preview.
- Made global shortcuts configurable in `[shortcuts]` and recordable live in Settings › Shortcuts, with reload on save and the recorded chord shown as you type it.
- Rebuilt Settings on one design system: a resizable `920×660` window with a single rail, unified headers and controls, a `Workspace HUD` `Customize…` sheet with a Bottom/Top position choice, and `Activity` moved behind `[labs] activity`.
- Added an opt-in i3/sway-style Scratchpad behind `[labs] scratchpad`: summon, send and cycle hidden windows per display without leaving the workspace you're on.
- Extended display support past two monitors: Settings › Workspaces shows every connected display, three and four-plus monitors get named segments, and cross-display moves, focus history and workspace assignment keep working across all of them.

## Improvements
- Added a playable mini desktop to the last setup step, so the onboarding tour ends by tiling windows you can actually drag.
- Added `mouse_follows_focus` (`off | display | window`) to choose whether explicit focus actions move the pointer: `off` leaves the pointer where it is, `display` warps it to the focused window's display, and `window` also warps it within the same display when it is outside the focused window.
- Made `workspace_order` configurable, so the HUD, menu and swipe order follow your numbering instead of `1`–`10`.
- Added `spaceman ctl move WORKSPACE --follow` to move the focused window to that workspace and switch to it, and `spaceman ctl resize width|height POINTS` to resize the focused window.
- Added an `action = "tile"` rule and tiling for windows with an enabled zoom button, so previously untileable apps can be routed.
- Cycling focus now works everywhere: a repeat press of the active workspace cycles its windows, `focus next`/`focus prev` cycles floating windows, and `Option+Tab` keeps a cross-display focus history.
- Added `Option+Shift+<number>` to move a window to a workspace on another display.
- Added `spaceman://` deep links for Settings, features and Labs, with a web bounce for the website.
- Edge resizes grabbed from just outside a window now work, including the outer-edge left and right column drop bands.
- Added a programmatic macOS live gauntlet with JSON receipts, so a release's live behavior can be re-checked against a recorded baseline.

## Fixes
- Reflowed at once when a window is minimized and when an app is hidden with `⌘H` (732 ms → 37 ms), instead of waiting for the next observation cycle.
- Kept the macOS 27.3 beta permission guide off the system's Override buttons, so the "Open System Settings" path stays clickable.
- Stopped hidden windows peeking through a screen edge when parking fails, including the case where a display below blocks both corners.
- Preserved cross-desktop parked recovery metadata past the 30 s timeout, and waited out Space slides instead of shrinking outgoing tiles.
- Fixed `Cmd+Tab` out of native fullscreen, and made drag previews non-destructive so a cancelled drag leaves the arrangement untouched.
- Fixed Finder tiling by ignoring non-window Accessibility entries that carry no window ID, and stopped expiry modals and sheets from breaking tile slots.
- Improved focus reliability with Arc and other Electron apps: cancelled focus follows retry at the opening cadence, the app is brought forward so keys follow a switch, and superseded pending focus carries over.
- Fixed the CLI exiting on a broken pipe and TOML edits dropping detached comments or comment decor on tables that became empty.
- Fixed 3-display workspace naming, Base-modifier shortcut labels, shortcut chord reuse, and workspace `10` in the settings panes.
- Fixed dozens of focus, recovery and Scratchpad edge cases: pending floats relocated on move, floated size remembered across a switch away, hidden scratchpad windows re-parked on display add, and cross-display routed or recalled windows parked off their source display.
